# Local Quick Exit

This staged implementation uses the pinned Apparition source at commit `307e94c1b1d6537ba7a2a71b32a22d563d3ea25c`. `Menu/base.gsc:120–155` closes Main immediately on melee. On nested pages, its optional `QuickExit` branch distinguishes a tap from a held melee press: ten observations separated by nine `wait 0.01` calls produce a nominal 90 ms hold threshold. A tap returns to the parent. `Menu/menu_customization.gsc:63,505–508` exposes the boolean option and toggles it. An unset option is false.

The controller appends `Quick Exit [ Hold melee ]` to Menu Preferences, with default `quickExit=false`. Changing it updates immutable local appearance only. Native input owns the hold timing; the controller receives `close` and retains its current page, highlight, and parent path for reopening. `close` never requests Exit, calls session cleanup, cancels pending game work, or toggles a game feature. Existing Back behavior remains unchanged. The optional setting lives only for this controller's lifetime; this wave adds no disk persistence or saved-key writes.

Every state publishes `isRootMenu` from the actual navigation page, with Main as the root. Generic older producers default to `true`. This avoids interpreting a title as navigation identity. The immutable appearance record appends `quickExit`, while older seven-field objects default it to false. Existing preference and input enum values remain unchanged.

Close packets must carry an exact unsigned `navigationRevision` equal to the current navigation revision. The controller observes completed operations before this comparison and checks game focus again immediately before closing. Missing, malformed, foreign, stale, or focus-rejected packets cannot change navigation; trusted fresh sequences are acknowledged once and cannot replay after correction. Other command inputs retain their legacy envelope shape, with an optional strict unsigned revision.

The portable tests use a fake session boundary and cover option toggles, root and nested close, retained navigation, pending selection, asynchronous page changes, strict epochs, acknowledgment, and focus loss. The offline exporter preserves the original nine fixture states and appends `preferences-quick-exit.json` and `root-quick-exit.json`. Both new fixtures are PREVIEW snapshots with committed local Quick Exit; game features remain unavailable. Native hold timing and rendering require their separate fixture regressions. No game or installed package is changed by these backend tests.
